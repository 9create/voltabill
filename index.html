⚡ Volta Command Guide

Type these commands in the Volta AI chat box (⚡ button, bottom right)

📄 Invoice / Quotation

ci [buyer] itm=[item] qt=[n] rt=[price]Create Invoice
cq [buyer] itm=[item] qt=[n] rt=[price]Create Quotation
inv no=INV-001Set invoice number
buyer=[name] addr=[address]Set buyer details
gstin=[15 digit]Set buyer GSTIN

➕ Items

add itm=[name] qt=[n] rt=[price]Add single item
add 3 items: LED 100@500, fans 50@2000Add multiple items
replace itm=[name] qt=[n] rt=[price]Replace ALL items
remove duplicate itemsAuto-remove duplicates
clear itemsClear all items

🏢 Seller

fill seller [company name]Fill seller details from DB
